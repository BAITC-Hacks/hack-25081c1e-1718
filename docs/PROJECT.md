# Tariflow — задача и границы

Tariflow помогает маркетинговому аналитику планировать тарифные кампании:
выбрать аудиторию, тариф и канал при неполной информации об эффекте перехода.
Все данные кейса синтетические; реальные действия в отношении абонентов не выполняются.
Источник: [guide организаторов](../PARTICIPANT_GUIDE.md) и
[исходное ТЗ с рубрикой](CHALLENGE_ORIGINAL.txt).

## Обязательный результат

- `agent.py` с `Agent.act(env) -> list[dict]`.
- От 1 до 10 корректных кампаний с существующими тарифами и каналами.
- Хотя бы один успешный `env.run_pilot`; наблюдения влияют на решение.
- Соблюдение всех лимитов, включая пилотные расходы и контакты.
- `submission.csv`, созданный официальным `make_submission.py`.
- `requirements.txt` для используемых библиотек; README для воспроизводимости.

| Ограничение | Значение |
|---|---:|
| Бюджет с пилотами | 100 000 у.е. |
| Контакты с пилотами | 15 000 |
| Финальные кампании | 1–10 |
| Аудитория кампании | До 5 000 |
| Пилоты | До 20 |
| Размер пилота | 10–200 |
| Время по guide | До 10 минут |

Эффект пропорционален `predicted_arpu`. Чистый прирост — эффект по уникальным
абонентам минус расходы на все контакты. У повторного абонента учитывается лучший
эффект, но стоимость повторных контактов сохраняется. Базовая выручка не является
приростом. Каналы: push — 0, SMS — 4, digital_ads — 22, call — 160 у.е. за контакт.

## Реализованный сценарий

Профиль и публичная история → кандидаты → пилоты → обновление оценок → допустимый
план → официальный CSV. Необязательная веб-оболочка запускает расчёт, показывает
результаты и объяснения с источниками на русском или казахском. OpenAI — ограниченный
советник; без ключа и при ошибке API сохраняется автономный режим.

Стек: Python 3.12, pandas, NumPy, стандартная библиотека; веб на HTML/CSS/JavaScript
без npm-зависимостей. Контракты — [ARCHITECTURE](ARCHITECTURE.md), [API](API.md),
[REPORT_SCHEMA](REPORT_SCHEMA.md). Команды — [README](../README.md).

## Данные и границы

История относится к другой выборке: совпадения ID с целевой базой не используются
как доказательство соответствия. Читаются только разрешённые CSV и публичный API
среды; скрытые эффекты и внутреннее состояние не исследуются. Ключи берутся только
из окружения. Реальные CRM, авторизация, БД и рассылки в проект не входят.

Guide допускает LLM и 10 минут, комментарий шаблона указывает отсутствие интернета
и 5 минут. Решение поддерживает автономный запуск менее 5 минут. Неизвестные эффекты
судейской среды не позволяют гарантировать балл или коммерческую прибыль.

Оценка: работоспособность 25, техническая реализация 25, README и воспроизводимость 25,
ценность 15, развитие и оригинальность 10. Подтверждённые проверки и ограничения —
[VALIDATION](VALIDATION.md). Факт загрузки организаторам отдельно не подтверждён.
