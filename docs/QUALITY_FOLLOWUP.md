# Проверка подтверждений и размера пилота

План зафиксирован 23.09.2026 до выполнения новых серий. Это продолжение по
прямому запросу пользователя. Предыдущие неудачные эксперименты сохранены в
[QUALITY_RESULTS.md](QUALITY_RESULTS.md); их результаты не переименовываются
в независимую проверку. Метрика — чистый прирост в синтетической среде,
не «точность детекции» и не будущая оценка жюри.

## Зафиксированные варианты

Полный baseline: `c86c392`. Данные и candidate_model/analysis заморожены.
Production Agent() пока baseline/template/fixed.

1. `confirmation_first`: прежнее balanced-начало 3/3/2, затем сначала
   зарезервированный повтор, затем перспективные наблюдённые варианты, потом
   новые пары. Старый `balanced` сохраняется без изменения.
2. `adaptive`: порядок baseline, адаптивный размер повторного пилота.
3. `adaptive_confirmation`: оба изменения вместе.

Размер первого scout-пилота остаётся 150, первого пилота нового платного канала —
200. Для повторов используем только фактические завершённые наблюдения
этого же варианта/канала: расстояние среднего lift от точки безубыточности
`cost_per_contact / average_predicted_arpu`. Инвертируем существующий
эвристический запас `0.8 * 0.07 * sqrt(150 / total_n)` и ограничиваем следующий
размер диапазоном 50–200, затем размером аудитории. Около границы берём 200.
Это эвристика, не калиброванный доверительный интервал. Даже если расчётное
число наблюдений достигнуто, выбранный повтор использует минимум 50: допуска
без второго собственного пилота нет, а порядок/число попыток здесь не меняем.
Резерв новых пар остаётся консервативным (до 200 на повтор).

## Порядок проверки и принятия

- Разработческая серия **200–209**: baseline и три новых варианта; отдельно
  старые balanced/empirical/combined для сопоставимости на тех же seed.
- Выбрать ровно один новый вариант по максимальной медиане; при равенстве по
  p10, затем по меньшему числу изменённых механизмов, затем по имени.
- Зафиксировать выбор и SHA до просмотра **300–319**.
- Независимая серия 300–319: только baseline и зафиксированный вариант,
  без подбора параметров после просмотра результата.
- Замена default только если одновременно: медиана ≥110% baseline,
  положительная медиана парного изменения, p10 не хуже, отрицательных не больше,
  ноль ошибок/нарушений, каждый запуск ≤300 секунд. Иначе сохраняем baseline.

Каждый запуск — отдельный процесс из полного неизменяемого Git-снимка.
Сохраняем хеши, результаты по seed, размеры пилотов и причины исключения.
Скрытые эффекты и внутренности среды не читаем. Новых вызовов OpenAI эта серия
не делает. Параметры прошлого holdout и старые доказательства не меняются.

Результаты добавляются ниже после выполнения, отдельно от этой фиксации.
