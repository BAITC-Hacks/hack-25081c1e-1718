# Azim — передача диагностического UI, README и демо

## Готово

В своей зоне `web/**` и `docs/DESIGN.md` завершил блок QUALITY_STAGE: исследованные гипотезы и варианты каналов, повторные пилоты, выбранные варианты, расходы пилотов, причины исключения, собственные источники кампании, разброс и метод эвристической неопределённости. Отдельный блок сравнивает области данных без ложной «ошибки прогноза»: `forecast_summary` — только финальные кампании, `evaluation` — пилоты и финальные кампании с дедупликацией. Q&A refs `selection_diagnostics` и `forecast_summary` открывают свои блоки только при наличии полей. Старый JSON остаётся совместимым, отсутствующие значения — «нет данных». RU/KK сохранены.

README теперь даёт точный путь из чистого checkout к официальному evaluator и CSV, архитектуру/отличия/ограничения, текущий состав ZIP и только результаты нового проверенного отчёта Димы для `9a1b3b1`. В нём указан неудачный независимый gate, default baseline/template/fixed, без обещания улучшения. DEMO — двухминутный сценарий с реальными областями данных и запасным путём; шесть скриншотов RU/KK на 375/768/1440 лежат в `web/screenshots/`.

Реальный локальный offline seed42: 299 созданных/8 исследованных гипотез, 10 вариантов канала, 6 повторно проверенных, 3 выбранных; расходы пилотов 28 800; прогноз 1 016 224,93 / осторожный 673 432,82; факт всей симуляции 685 149,52. Это значения снимка, не UI-константы и не доказательство улучшения алгоритма.
