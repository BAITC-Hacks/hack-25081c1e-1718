## Запуск веба

```powershell
python -X utf8 scripts/run_agent.py --offline
python -m http.server 8080 --bind 127.0.0.1 --directory web
```

Открыть http://127.0.0.1:8080 → «Открыть отчёт» → `output/report.json`. До импорта нет фиктивных KPI. Кнопка сохранённого отчёта необязательна: она ищет `web/report.json`; при отсутствии предлагает импорт. Отчёты/фикстуры/снимки остаются локальными. CSV из UI вспомогательный; официальный submission создаёт make_submission.py.
