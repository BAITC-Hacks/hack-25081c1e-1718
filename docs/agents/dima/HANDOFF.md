## Что подхватить Азиму

Сделать pull main, прочитать PROJECT/WORK_PLAN/ARCHITECTURE и подтвердить своё владение в STATUS. Приоритет — candidate_model.py: build_candidates(profile, tariffs, data_dir) по указанному контракту. Только разрешённые исторические CSV; ID истории и целевой базы не пересекаются. После интеграции — web/ и README. Для UI реальный отчёт создаётся командой python -X utf8 scripts/export_report.py --seed 42; output/report.json локальный и игнорируется Git. Секреты в отчёте отсутствуют.

Дима реализовал llm_advisor.py, оркестрацию/адаптацию и бюджетный контроль в agent.py. Candidate module автоматически импортируется с тремя аргументами (profile, tariffs, data_dir). При отсутствии модуля встроены узкие ценовые гипотезы; перенос исторических медиан оказался неустойчив. Не менять agent.py, llm_advisor.py, scripts/контракты без координации. Личные LOG/HANDOFF/STATUS каждый обновляет сам. Полная инструкция запуска и подключения — docs/RUNBOOK.md.
