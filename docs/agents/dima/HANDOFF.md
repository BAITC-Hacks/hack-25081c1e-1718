## Текущее состояние

Кейс объявлен: тарифные маркетинговые кампании Beeline. Цель — положительный net ARPU через пилоты и адаптивный выбор кампаний. Полное ТЗ в docs/PROJECT.md, расписание 300 минут в docs/WORK_PLAN.md, интерфейсы в docs/ARCHITECTURE.md. Пакет организаторов скопирован без изменений в корень; runner импортирует agent.py.

Подготовлен первый каркас: baseline с 12 пилотами, 3 финальными кампаниями, submission.csv и scripts/export_report.py. Seed 42: net −19 097.41, evaluator FAIL; 2 положительных seed из 10. Не представлять каркас как экономически готовое решение. docs/BASELINE.md содержит ограничения и измерения. Первый checkpoint выполняется после этой записи; SHA доступен через git log.

## Что подхватить Азиму

Сделать pull main, прочитать PROJECT/WORK_PLAN/ARCHITECTURE и подтвердить своё владение в STATUS. Приоритет — candidate_model.py: build_candidates(profile, tariffs, data_dir) по указанному контракту. Только разрешённые исторические CSV; ID истории и целевой базы не пересекаются. После интеграции — web/ и README. Для UI реальный отчёт создаётся командой python -X utf8 scripts/export_report.py --seed 42; output/report.json локальный и игнорируется Git. Секреты в отчёте отсутствуют.

Дима внедряет llm_advisor.py, оркестрацию/адаптацию и бюджетный контроль в agent.py. Пользователь явно запросил OpenAI в цикле решения. До подключения ключа всё работает автономно. Не менять agent.py/scripts/контракты без координации. Личные LOG/HANDOFF/STATUS каждый обновляет сам.
