# Передача от Димы — исправления ответов и финальная поставка

## Текущее состояние

Принят интерфейс Азима b1d4fbe: Compass, история вопросов, различимые сегменты.
Моя зона — core/server/report_assistant/scripts/общая интеграция; web не менял.
Этот checkpoint исправляет реальные ошибки ответов:

- Вопрос о конкретной кампании получает только её allocation и собственные
  завершённые пилоты с совпадающими candidate/channel/target/filters.
- Общий результат evaluator исключён из такого контекста.
- Номера до/после слова «кампания», порядковые слова, списки и диапазоны распознаются.
  Отсутствующие номера явно отмечаются; offline-сравнение не обрезается после третьей.
- Бюджет конкретной кампании объясняется её расходами.
- Неопределённость передаётся модели в процентных пунктах. Найденная путаница с
  процентами отклоняется с честным offline-пояснением и сохранением известного usage.
- Свободный текст модели всё ещё требует сверки; проверки не доказывают каждое
  утверждение и не обещают реальную прибыль. Каждый вопрос независим.
