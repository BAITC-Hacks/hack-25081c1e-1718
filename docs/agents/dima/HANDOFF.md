## Азиму — можно подключать сейчас

`python -X utf8 server.py --offline` или `python -X utf8 server.py --ask-key`, затем http://127.0.0.1:8765. Без первого расчёта GET report404 — это нормальное пустое состояние. Пользовательский локальный импорт не получает server report_id. Режим расчёта offline/openai независим от чата: чат использует включённый серверный OpenAI, иначе отвечает локально.
