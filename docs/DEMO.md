# Двухминутное демо Tariflow

Владелец: Азим. Показываем только учебный синтетический кейс; настоящие рассылки не запускаются. Числа произносим из открытого отчёта конкретной ревизии, а не по памяти. Официальный `submission.csv` формируется отдельно от веб-экспорта.

## Подготовка

Из чистого checkout выполните [команды README](../README.md#запуск-из-чистого-checkout) с Python 3.12. Для живого показа запустите `python -X utf8 server.py --offline`, откройте <http://127.0.0.1:8765> и оставьте seed 42. При старте сервер ещё не имеет отчёта: пустое состояние корректно. Если нужен заранее сохранённый результат, выполните `python -X utf8 scripts/run_agent.py --offline` и импортируйте `output/report.json` на статическом viewer; такой файл обозначается как сохранённый и не доступен для серверного чата.

Перед показом проверьте язык RU/KK, доступность локального API, первый запуск или свежий снимок, ссылки источников и отсутствие ошибок консоли. Учетная запись и ключ OpenAI для воспроизводимого демо не нужны. Если показываете OpenAI отдельно, включите его только через серверный `--ask-key`, дождитесь фактического ответа и прочитайте метку режима; автономный fallback нельзя называть ответом модели.

## Сценарий — 120 секунд

| Время | Действие | Что сказать |

| 0:15–0:35 | Нажать «Запустить анализ», дождаться реального статуса и отчёта | «Агент формирует гипотезы и тратит пилотные ресурсы. Процент прогресса не придуман — ждём ответ сервера». |
| 0:35–0:55 | Обзор: фактический net, остатки после пилотов и плановый остаток | «Это измеренный итог данной синтетической симуляции. Контакты и бюджет показаны в двух разных стадиях; официальный evaluator и CSV проверяются отдельно». |
| 0:55–1:15 | «Что исследовал агент», открыть причины и один пилот | «Счётчики гипотез отличаются от вариантов с каналом. Повторная проверка не равна положительному эффекту. Здесь видны расходы и причины исключения». |
| 1:15–1:35 | «Прогноз плана и итог расчёта», затем раскрыть кампанию | «Прогноз охватывает только финальные кампании, факт — всю симуляцию с пилотами. Разность не является ошибкой прогноза. Запас неопределённости эвристический». |
| 1:35–1:50 | Нажать «Обсудить с агентом» у конкретной кампании, отправить вопрос, открыть ссылку | «Номер кампании подставлен, но отправку подтверждаем вручную. Ответ опирается на собственные пилоты этой гипотезы и канала». |

Если времени мало, показывайте один вариант и один источник. Не называйте предварительный прогноз фактическим эффектом, 5/5 технических must-have — гарантией 100 баллов, а подготовленный ZIP — подтверждением отправки.

## Запасной путь

Если локальный API недоступен, импортируйте фактический `output/report.json` и сразу назовите его сохранённым расчётом. Отсутствующие поля старого report 1.0 показываются как «нет данных»; объяснять их вымышленными цифрами нельзя. При ошибке расчёта покажите текст ошибки и восстановление. При отказе OpenAI используйте реальный автономный ответ с предупреждением или покажите ошибку; заготовленный ответ не подставляйте.

## Проверка перед передачей

Пройдите клавиатурой переключение языка, раскрытие причин, кнопки пилотов и ссылки ответа; фокус должен быть виден. Проверьте загрузку, ошибку API, отсутствие отчёта, старый JSON без диагностик, отрицательную осторожную оценку и нулевые значения. На реальном автономном seed 42 эти состояния проверены в Edge; на **375 / 768 / 1440 px** у RU и KK не было горизонтального переполнения или JS-ошибок. Шесть фактических снимков обзора лежат в полном репозитории: `web/screenshots/overview-{ru,kk}-{375,768,1440}.png`. Снимки не входят в маленький ZIP агента и не служат экономическим доказательством. Экономические итоги и хеши поставки — из проверенного отчёта Димы [QUALITY_FOLLOWUP](QUALITY_FOLLOWUP.md) для чистой ревизии `9a1b3b1`; результат новой UI-ревизии должен пройти свою проверку.

Сборка отдельной поставки: `pwsh scripts/verify.ps1 -Release`, затем `python -X utf8 scripts/package_submission.py`. Для upload берите `agent.py`, `submission.csv`, `requirements.txt` из `output/submission/`. Способ и факт загрузки организаторам подтверждает команда.
