# Двухминутное демо Tariflow

Владелец: Азим. Только синтетический учебный кейс; реальные рассылки не запускаются.

## Подготовка

Использовать Python3.12 и зависимости из README. Создать фактический снимок командой:

```powershell
python -X utf8 scripts/run_agent.py --offline
```

Для независимого viewer: `python -m http.server 8080 --bind 127.0.0.1 --directory web`, затем http://127.0.0.1:8080. На статическом сервере запуск и чат должны честно сообщать, что API недоступен. Импорт `output/report.json` работает локально.

Полный сценарий: `python -X utf8 server.py --offline`, затем http://127.0.0.1:8765. Для OpenAI: `python -X utf8 server.py --ask-key` (ключ вводится скрыто только в терминале); браузер не принимает ключи. После запуска сервера нет снимка, это корректное пустое состояние. Открыть страницу с чистого состояния; выбрать автономный режим для воспроизводимого показа. Режим чата определяется сервером и не переключается выбором режима анализа.

## Резервный путь

Если API недоступен, сразу импортировать фактический `output/report.json`; не показывать сохранённый снимок как новый запуск. Чат импортированного JSON недоступен по контракту: файл не передаётся серверу. При сбое OpenAI показать реальный автономный ответ с меткой режима либо ошибку, не заготовленный ответ.

Снимки обновлённого интерфейса сохраняются локально в `output/design-refresh/`; используем их, если браузер не может открыть страницу. Числа в речи читать с загруженного отчёта, не заучивать прошлый seed. В разделе «О результате» можно показать источник, дату, ограничения и остатки ресурсов. Служебные подписи о мероприятии удалены из рабочего интерфейса по запросу пользователя; сам расчёт не превращается в проведённую рассылку.

## Поставка

После официального `pwsh scripts/verify.ps1 -Release` запустить `python -X utf8 scripts/package_submission.py`. Для отдельных upload брать `agent.py`, `submission.csv`, `requirements.txt` из `output/submission/`. ZIP содержит также справочный manifest. Публичные CSV организаторов нужны в среде исполнения и в архив не включены. Форму upload и дедлайн подтверждает команда.

### Двуязычный показ

Внизу левой панели (на телефоне рядом с логотипом) выбрать **Қазақша**: разделы Шолу / Науқандар / Сынақтар / Агенттен сұрау / Нәтиже туралы. Открыть карточку и нажать **Агентпен талқылау**, затем **Жіберу**: агент отвечает на казахском, ссылки открывают исходные доказательства. Переключение на Русский сохраняет отчёт и историю; старые сообщения остаются на исходном языке. С сервером до161473c UI сообщает, что ответы доступны только на русском. Для полной демонстрации нужен актуальный server.py.
