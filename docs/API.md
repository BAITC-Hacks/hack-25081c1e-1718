# Локальный API рабочего интерфейса — v1

Статус: сервер реализован в `server.py`, ответы по отчёту — в `report_assistant.py`. Проверены настоящий offline-запуск, online-запуск с двумя успешными советами OpenAI и ответ OpenAI со ссылками на отчёт. UI интегрирует Азим. Заглушки допустимы только для локальной разработки с явной меткой.

## Транспорт

Одинorigin: `http://127.0.0.1:8765`, сервер отдаётweb/ иAPI. UI использует относительныеURL `/api/...`. Статический viewer на8080 сохраняет импортJSON; еслиAPIнет, явно предлагает запустить локальныйсервер. Никакихключей в браузере,localStorage,URL илиGit. Сервер получаетOPENAI_API_KEY из своегоокружения или скрытоговводаCLI.

ВсеPOST: `Content-Type: application/json`, заголовок `X-ARPU-Token` изhealth. Origin обязателен и долженсовпадать сHost сервера; никакогоCORS. Максимум16KiB наJSONзапрос, сообщение до2000символов. Всеошибки JSON: `{"error":{"code":"stable_code","message":"Понятное описание"}}`. HTTP400 невалидныйввод;403 origin/token;404 отсутствующийобъект;409 занятойресурс;429 частотныйлимит;503 OpenAIне настроен/сервис недоступен. Ответы no-store.

## GET /api/health


configured — ключесть, enabled — не выключенARPU_OFFLINE. Это конфигурация, не доказательство успешногоAPIвызова. Получатьtokenприоткрытии; не сохранять. Приперезапуске403 → однократно обновитьhealth и предложитьповторитьдействие, не повторять платныезапросы автоматически.

Отчёт из локальногоимпорта вбраузере сам по себе не получаетserverreport_id и недоступенserverчату; длядиалога загрузитьснимок сервера/сделатьновыйзапуск. Не отправлятьпользовательскийJSON вчат.

## POST /api/runs

Тело: `{"mode":"offline","seed":42}`. mode толькоoffline/openai; seedцелое0..4294967295. OnlineбезenabledAPI →503 openai_unavailable. Разрешён одинрасчёт одновременно; повторный →409 run_busy. Не принимать произвольныекоманды,пути,модель,ключи,бюджеты илифильтры.

202: `{"run_id":"opaque","state":"running"}`. UI опрашиваетGETстатус раз в1–2секунды, отключаетдублирующийзапуск, показываетреальнуюстадию. Таймаутсервера300секунд. Seed — расширеннаяопция, поумолчанию42.

## GET /api/runs/{run_id}

Временные метки запуска имеют ISO-8601 UTC суффикс `Z` (например, `2026-09-23T10:08:12.123456Z`), совместимый с web/api.mjs.

```json
{"run_id":"opaque","state":"running","stage":"evaluating","mode":"offline","seed":42,"started_at":"ISO-UTC","finished_at":null,"report_id":null,"error":null}
```

state: running/completed/failed. stage: evaluating/ready/failed. Послеуспехаreport_id заполнен, GET/api/report возвращаеттотжеснимок(сравнитьID). Послеошибкипредыдущийотчёт сохраняется и не отображаетсякакновый. error приошибке —объектcode/message. Неставитьнесуществующийпрогресс процентов/пилотов в UI.

## POST /api/chat

Тело: `{"report_id":"opaque","message":"Почему выбран этот канал?"}`. Нуженсуществующийснимок сервера; неизвестныйID →404 report_not_found. Одинответодновременно;409 chat_busy. Сервер отвечает пофактамконкретногоотчёта; диалог не изменяетплан, не запускаетрассылки и не выполняеткоманды. Наэтомэтапекаждыйвопроссамодостаточный, историяпоказываетсялокально, сервернаяпамятьдиалога не обещается.


mode: openai/offline. Безключа/приотказеAPI — честныйавтономныйответ сwarning; не изображатьподключённуюмодель. Ссылки: evaluation,resources,planned_resources,allocation.0..9,pilots.0..19; доступнытолько еслиобъектесть втомжеотчёте. UI умеетперейти/подсветитьсоответствующийблок; неизвестныеrefs не делатькликабельными. answer/labels выводитькакtextContent. usage — числафактическоговызова, отсутствиевызова0; не изображатьточнуюстоимость в$безтарифноймодели.

## Ограничения реализации

Сервер после запуска начинает без снимка: GET `/api/report` возвращает 404 до первого успешного собственного расчёта. Существующий `output/report.json` автоматически не импортируется. Каждый запуск пишет в `output/runs/<run_id>.json`; сервер проверяет совпадение `provenance.run_id`, seed и времени создания, затем сохраняет копию в памяти. История последних 10 снимков и 20 запусков живёт до перезапуска сервера.

Разрешены только `index.html`, `styles.css`, `app.mjs`, `report.mjs`, `api.mjs`, `integration.mjs`; новые статические пути согласовать с Димой. До 16 одновременно обслуживаемых соединений, один расчёт и один ответ; до 6 запусков и 12 вопросов в минуту. Сверх лимита соединений сокет закрывается. `usage` содержит известные значения, возвращённые провайдером; при сетевом сбое нули означают отсутствие полученных данных о токенах, а не доказательство отсутствия расходов.

Bindтолькоloopback, фиксированныйсписокstaticфайловweb; нетдоступа ккорнюрепозитория/output/env. APIнепринимаетключи. Дочернийзапуск —фиксированныйскрипт исписокаргументов, безshell; offlineпроцесс безOPENAI_API_KEY. Приуспехе проверяютсясвежесть,seed,схема иvalidation новогоJSON; сервер хранит неизменяемыйснимокподreport_id. Ошибкибезсырыхproviderответов/stdout/секретов. Report1.0 иконтрактAgent.act сохранены.
