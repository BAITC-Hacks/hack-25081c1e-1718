# ARPU Compass — веб-демо

Статус: brief и договорённости, реализации UI пока нет. Владелец web/: Азим, после рабочего вычислительного ядра.

## Brief

- Пользователь: маркетинговый аналитик.
- Задача: проверить предложенный план, затраты, результаты пилотов и причины выбора.
- Тон: точный, спокойный, деловой.
- Направление: светлый аналитический экран, тёмная типографика, сдержанный жёлтый акцент.
- Главный экран: импорт фактического JSON отчёта, ресурсы, ход пилотов, кампании.
- Главное действие v1: «Открыть отчёт»; экспорт таблицы — вторичное действие.
- Метка «Синтетические данные хакатона» видна всегда; сохранённый прогон подписан.
- Никаких обязательных интернет-шрифтов, внешних ресурсов или реальных рассылок.

## Структура экрана

1. Название + короткий смысл продукта + seed/время фактического прогона.
2. Ресурсы: оставшиеся бюджет, контакты и пилоты; недоступные метрики обозначать как «нет данных».
3. Пилоты: сегмент, целевой тариф, канал, размер и наблюдённый эффект. Оценки надёжности выводить только если они рассчитаны и объяснены.
4. Кампании: 1–10 строк с фильтрами, тарифом, каналом, доступным обоснованием.
5. Ограничения результата и выгрузка. Прибыль показывать только из evaluator, не из придуманных значений.

## Токены

CSS variables в web/styles.css. Светлый фон #F5F7FA, поверхность #FFFFFF, основной текст #17212B, вторичный #465565, акцент #F5C518 с тёмным текстом #17212B. Focus #1D4ED8. Ошибка #B42318, успех #166534 на белом. Фактический контраст всех использованных пар проверить при реализации.

Шрифт: system-ui; шкала 12/14/16/20/28/36 px. Отступы 4/8/12/16/24/32. Радиусы 8/12. Тень только у приподнятых элементов: 0 4px 16px rgba(23,33,43,.08). Компоненты используют токены.

## Состояния и доступность

- До импорта: объяснение формата и кнопка открытия, без фиктивных KPI.
- Чтение: loading; ошибка JSON/версии/полей: понятный текст и повторный выбор.
- Нет кампаний: явный статус неуспешного/неполного прогона, не изображать готовую отправку.
- Кнопки: hover/focus-visible/active/disabled; видимый фокус и подпись file-input.
- Состояния не зависят только от цвета; таблица со заголовками; управление с клавиатуры.
- На узком экране таблица имеет доступный горизонтальный скролл либо карточки строк.
