# ARPU Compass — рабочее место маркетолога

Владелец: Азим. Этап после viewer 593667d; без смены framework и зависимостей. Данные синтетические, реальные рассылки не выполняются.

## Задача и сценарий

Маркетолог выбирает обоснованный план и проверяет расход ресурсов. Путь: **запустить анализ → увидеть итог и рекомендации → открыть доказательства → спросить агента**. Импорт JSON остаётся самостоятельным путём без сервера.

1. Старт: ценность продукта, главное действие «Запустить анализ», выбор автономного/OpenAI режима, фактический статус API и ключа. При недоступном сервере — объяснение и импорт. Поля для ключа нет.
2. Обзор: крупный фактический net из evaluator, число кампаний/пилотов; ресурсы после пилотов и после плана; лучшие рекомендации, риски.
3. Кампании: карточки с целью, каналом и прогнозом в видимой части; details раскрывает фильтры, стоимость, охват и доказательства пилотов. Прогноз allocation не является фактом.
4. Доказательства: пилоты и предупреждения. Ссылки агента ведут к существующим данным текущего отчёта и открывают нужную вкладку.
5. Вопрос: текст, режим, безопасный ответ, фактический режим ответа и доказательства. Смена отчёта сбрасывает предыдущий ответ. Ошибка API не заменяется придуманным советом.

## Визуальное направление и токены

Компактная тёмная навигация, светлая просторная область, жёлтый акцент. Встроенные SVG, без внешних ресурсов. Эффект и рекомендации читаются без горизонтального скролла. На телефоне — компактная навигация и карточки в колонку; таблица доказательств прокручивается внутри своей области.

CSS variables в web/styles.css — источник фактических токенов. Семантические группы: фон/поверхность, основной/вторичный текст, граница, жёлтый акцент с тёмным текстом, тёмная навигация со светлым текстом, focus/успех/ошибка. Компоненты используют токены.

Системные шрифты; выразительный заголовок и tabular-nums для чисел. Минимум 12 px, основной текст 14–16 px, заголовки 28–48 px. Ритм отступов 4/8/12/16/24/32/48, радиусы 8–20 px. Декор не конкурирует с результатом.

## Состояния и доступность

До запуска нет выдуманных метрик. Импорт подписан «Сохранённый прогон», время/seed доступны. Проверка подключения, запуск/ожидание имеют текстовые статусы без вымышленных процентов. Повторная отправка заблокирована; ошибка даёт восстановление.

OpenAI без ключа обозначен явно; автономный режим доступен при доступном сервере. Ключ только в окружении сервера. Сетевой сбой не скрывает сохранённый характер открытого отчёта. OpenAI, fallback и автономный ответ различаются фактическим режимом.

Ошибка импорта не оставляет старый отчёт под новым названием. Пустой результат объясняется без обещаний прибыли. Отрицательный net виден, ноль не заменяется отсутствующим значением.

Логические заголовки/landmarks, skip-link, подписи полей, видимый focus, вкладки и details с клавиатуры, aria-live. Контраст обычного текста минимум 4.5:1, крупного 3:1. Цвет дополнен подписью. Respect prefers-reduced-motion.

Модельный и импортированный текст — textContent. Доказательства — проверенные внутридокументные ссылки, произвольный URL/HTML не исполняется. Никаких ключей в frontend/browser storage/Git. API отделён от представления; контракт Димы в docs/API.md.
